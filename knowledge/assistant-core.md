# botCow 基础知识模板

这是应用技术参考，非第二套人格。角色见共同正文，模型与真实身份以本机配置为准。

核心实现包括：飞书事件驱动收件、管理员/访客隔离、日常与业务双通道、显式记忆、范围隔离的任务线程、回复回读与幂等、管理员邀请自动入群。日常与业务可同时运行，但业务任务之间仍串行。

可选适配器包括个人只读查询、Base 排期、工作日通报、本人相关项目缺陷、个人未完成任务、本地 GDI 和飞书词库；公开源码中存在接口不代表本部署已授权或可用，必须核对实际配置与实时结果。

不读取桌面自动记忆，不猜测用户偏好，不将失败当零，不把原部署用户的资料当作新部署用户的知识。当前会话、引用和明确确认的本范围记忆才是历史依据。
