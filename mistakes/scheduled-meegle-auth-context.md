# 交互授权成功不能代替计划任务验收

- 日期：2026-11-13
- 现象：首次上线后，10点卡片中的Dobe Bug显示未能读取；手动查询正常。
- 已确认原因：相同Windows用户在交互环境和计划任务环境下看到的Meegle凭据存储不同。计划任务user me返回authentication required，其HKCU下Meegle keychain键不存在，交互环境存在。
- 原实现遗漏：只做交互式只读预演，没有在真实计划任务principal下验证；错误被统一压为query_failed，丢失定位信息。
- 修复：在计划任务运行环境使用官方OAuth，由用户完成授权；独立进程零写入复测读取7条本人关联未关闭Bug并成功生成1卡。保存安全错误分类和步骤；不复制凭据、不扩大查询范围。
- 防呆：部署无人值守任务必须用相同principal/运行环境实测只读链路；不以用户名相同或CLI登录成功推断可用。错误同时检查stdout/stderr；授权错误不重试、不报零。
