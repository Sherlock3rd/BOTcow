# 消息搜索时间参数与空结果的区别

日期：2026-11-14。

- 风格重新取样时，消息搜索最初缺search:message；用户完成授权后，使用带毫秒UTC终点的请求仍返回99992402、field validation failed。这是参数错误，不是空结果，也不是授权失败。
- 检查dry-run后，将起止时间统一成YYYY-MM-DDTHH:mm:ss+08:00，按年及全范围搜索均成功。没有单独实验区分毫秒和时区格式各自的影响，不将观察写成已定位SDK内部根因。
- 历史列表和消息搜索是独立核对来源。只有ok=true、返回消息数组、has_more=false的空页才能记录当前范围无可读结果；任何错误都必须保留失败状态。
- 名称解析返回的P2P会话可用于直接按chat-id读取，避免为已经明确的目标重复申请用户ID解析所需的会话权限。
- 新说明只使用匿名代称，不记录姓名、账号标识、授权链接或设备码。
