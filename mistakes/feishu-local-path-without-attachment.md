# 飞书对话不能只回复本机文件路径

## 基本信息

- 日期：2026-07-31
- 分类：飞书即时通讯 / 审阅文件交付
- 任务：通过“牛马小助手”交付 GDData HTML 对比页

## 问题现象

- 机器人在飞书中回复了本机 HTML 路径，但没有发送文件附件。
- 用户无法在飞书对话中直接查看审阅内容。

## 原因分析

- 对话桥只处理了文字回复，没有把本地审阅产物纳入消息完成条件。
- 本机路径只对运行机器有效，不是飞书用户可访问的交付物。

## 修复动作

- 将当前 HTML 审阅页作为文件附件发送到飞书单聊。
- 对话桥新增规则：任务产生本地审阅文件时，必须发送附件；文字与附件全部成功后才能标记入站消息。

## 预防办法

- 回复中出现本地文件路径前，检查该文件是否已作为附件发送。
- 为同一入站消息的文字回复和附件分别使用稳定幂等键。
- 任一必需附件发送失败时保留队列事件，避免把未完成交付误标为已处理。

## 执行前检查项

- [ ] 已确认附件路径存在且文件可读。
- [ ] 已从附件所在目录使用相对路径发送。
- [ ] 飞书返回 `ok=true`。
- [ ] 所有必需附件发送成功后再标记队列。
