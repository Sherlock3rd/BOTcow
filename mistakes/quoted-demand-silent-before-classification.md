# 引用需求跳过快速分类导致长时间无反馈

- 日期：2026-11-13
- 现象：17:24:47 收到群内“@牛马小助手 记录到文档”，约 95 秒后才添加 OnIt；17:28 完成群内回复，17:29 队列收尾。
- 原因：chatContext 找不到引用时，runGreeting 在调用轻量模型前直接移交业务执行器，模式保持 unclassified。需求执行器加载与读取后才完成分类，因此没有及时反馈；监听与准入正常。
- 修复：将 missingReference 显式传给轻量分类器。当前正文明确的工作请求可先分类 task 并立即添加 OnIt，再由执行器读取引用；其他结果不发送、不锁定 chat，仍交执行器读取后判断。
- 防呆：分类不代表授权写入；缺失引用必须在业务阶段读取。非需求和未分类不得贴表情。业务进程尚未结束时禁止重启监听或重复执行写入。
- 验证：回归覆盖缺失引用的明确需求、模糊问句、业务队列未启动时的 OnIt、重复派发去重；另做真实轻量模型合成输入验证，不发送测试群消息。
