# 错题记录

## 用途

- 记录可复现错误、原因、修复动作和预防检查项。
- 新任务开始前，先按任务关键词检索本目录。
- 本目录没有相关记录时，再检索 `D:\example\Workbencch\mistakes\`。

## 命名

- 使用简短英文 kebab-case 文件名，例如 `feishu-write-target-mismatch.md`。
- 同类错误优先归并，不重复创建碎片化记录。
