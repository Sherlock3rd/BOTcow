# 飞书 open_id 不可跨应用复用

## 基本信息

- 日期：2026-07-31
- 分类：飞书即时通讯 / 用户身份解析
- 任务：让“牛马小助手”向用户发送首条单聊消息

## 问题现象

- 使用旧飞书应用下解析出的用户 `open_id`，通过“牛马小助手”应用发送消息时，接口返回 `open_id cross app`。
- 消息未发送。

## 原因分析

- 飞书 `open_id` 与应用绑定。
- 同一用户在不同飞书应用下对应不同的 `open_id`，不能跨应用直接复用。

## 修复动作

- 停止复用旧应用的用户 ID。
- 为 `botCow` 应用发起最小范围的用户授权。
- 授权后通过当前应用重新按姓名解析用户，再发送已确认消息。

## 预防办法

- 发送消息前确认用户 ID 是否由当前应用解析。
- 新建或切换飞书应用后，重新建立联系人 ID 映射。
- 不把其他 profile 的 `open_id` 写入当前应用配置。

## 执行前检查项

- [x] 当前 CLI profile 与执行发送的应用一致。
- [x] 收件人 `open_id` 由同一应用解析。
