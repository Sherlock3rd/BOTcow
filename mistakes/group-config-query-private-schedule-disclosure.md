# 项目配置查询附带私人排期链接

2026-11-14，用户在群内询问任务配置表位置，机器人回答项目配置后，又自行追加个人排期状态看板链接。问题属于项目配置，能力与资源可读取不等于可公开。

- 按用户要求撤回错误回复，飞书回读 deleted=true；不重发替代消息。
- 项目配置查询只答项目配置，不能把私人排期当作另一种解释。
- 私人排期的链接、记录、摘要、截图和附件不得发群；旧错误回复不是授权。
- scoped-reply 发送前动态读取本机排期目标，拦截文本/卡片等 JSON 中的 Base、表、视图标识；配置不可读时群回复失败关闭。错误信息不包含私人标识。
- 标识拦截不能识别无标识的自由文字摘要或图片内容，仍须遵守规则中的内容边界，不宣称是全内容识别器。
