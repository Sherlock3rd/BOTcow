# 记忆投影与自然语言边界

日期：2026-11-13，隔离测试发现并修复，未产生真实飞书记忆写入。

- SQLite 初始化在另一个进程持写事务时可能失败；构造函数中已经打开的连接必须在 schema 初始化失败后关闭，否则 Windows 留下文件句柄。数据库锁故障注入与清理验证已覆盖。
- 模型输出 memory/update 时曾把“把那条格式偏好改成……”整条指令放入 value。不能把“value 是用户原文子串”当成语义正确；对明确操作词按程序提取值，保留内容原文，混合业务只允许明确子句，不把业务操作一并保存。
- 查看记忆可能由模型直接回答；显式查看/回忆入口优先确定性解析，模型合同统一返回 list，数据库不可用与无记录分开。
- SQLite 与投影日志不是同一事务。先持久化投递账本，幂等投影重放；恢复不能重发消息。发送后没有取得确定回执时暂停核对。
- 遗忘必须覆盖回复、线程、延迟投影和旧备份；使用范围 epoch、发送前校验和独立单调 fence。回退不得恢复共享业务线程或删除 fence。

检查：故障测试不能只测正常路径；真实模型输出要验证操作和值；统一记录不能把工具口头成功、processed 或未经核对的回复当业务验收。
