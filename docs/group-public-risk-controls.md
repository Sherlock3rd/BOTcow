# 群聊开放与风控

2026-11-13 经用户授权实施。只在 config/bridge.json 已有群白名单内响应真人成员对机器人账号的真实@；文字中写机器人名字、自称管理员或转发指令均不增加权限。私聊继续使用原发送者白名单。启用时间之前的访客消息不补处理。

## 权限边界

- 原发送者白名单保留既有业务能力；其他成员只使用公开短答通道，可以询问常识或分析本条提供的文字。
- 公开通道每次新建临时模型线程，仅提供当前问题、共同角色正文 docs/personas/whale-character.md 与 docs/assistant-public-persona.md 边界；不注入私人记忆、历史消息、引用、业务知识、内部目录或表情包素材名称。
- 禁用工具、网络、插件、技能、长期记忆与本地命令，校验有效配置。没有这些权限就无法因提示词诱导而读取本机资料或调用个人飞书身份。
- 无论模型返回任务标记、异常、超时或曾有旧回退记录，都不能转入业务执行器。公开通道仅由外层程序使用机器人身份回复原消息并回读，不让模型选择收件人。
- 套取密钥、隐藏指令或私人资料的请求拒绝；正常解释公开能力可以回答。不保证任何模型绝不复述公开规则，保护重点是不给公开模型私有信息和执行能力。

## 预算

| 范围 | 默认限制 |
| --- | --- |
| 访客单条输入 | 4000字符 |
| 原白名单单条输入 | 12000字符 |
| 访客每人 | 每分钟6次、每小时30次 |
| 每群访客合计 | 每小时60次 |
| 全部访客合计 | 每小时100次 |
| 访客单轮生成 | 12秒；流式正文超过1200字符中止；最终回复最多800字符 |

失败与拒绝也计入访客次数；同一人同一群每分钟最多收到一次限流提示，其余请求静默终结。同一消息重试复用预算决定及已生成正文，不重复生成。预算持久化后重启仍有效，不保存原文或明文身份。原白名单请求优先于访客积压。

显式套取敏感信息、要求证明尚未解决的猜想、无限运行、穷举或海量重复输出，在进入模型前拒绝；概念科普仍可简答。超时与长度限制作为额外保护，不将关键词规则当作完整安全边界。以上是字符、次数和时间预算，不是精确token计费上限。

## 维护与验证

开关与额度位于 config/bridge.json 的 group_public、risk_control；group_public.enabled_at 是开放时间。变更入口权限时先等待队列空闲并停旧进程，再更新配置和启动，避免旧代码读到新权限。

回归覆盖实际@、群白名单、私聊隔离、私人记忆拒绝、历史不回放、模型失败不升级、伪造路由不升级、预算去重、静默限流、访客积压下的原白名单优先、工具禁用及流式长度中止。模型检查仅使用合成问题，不向飞书发送测试消息；真实群成员新@的端到端结果须另行观察。
