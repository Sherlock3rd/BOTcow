# botCow 项目综述

核对日期：2026-11-14。botCow 是 Windows 本机常驻的飞书—Codex 对话桥，事件到达后处理消息并回到原消息回复，不依赖桌面聊天保持前台。

## 输入与处理

- 管理员单聊支持文本、富文本、图片；群聊须在白名单内且真实 @ 机器人。
- 群内其他成员只使用限流的无工具短答，不加载历史、私人记忆或内部资料。
- 日常与业务通道独立，可以同时运行；各队列串行，业务执行器全局只运行一个。
- 日常回复回读后完成，不贴状态表情；需求分类后 OnIt，业务、回复和附件验收成功后 DONE，再完成队列。
- SQLite 保存当前用户及会话范围的显式记忆；任务线程隔离，旧共享线程不恢复。
- 唯一人格正文为 docs/personas/whale-character.md；身份、工具、权限与真实结果不由人格决定。

## 已接入流程

配置 Review、需求排期、授权本地 Skills、个人只读查询，以及工作日 10:00 的超时需求、本人相关未关闭 Bug、本人未完成任务播报。具体目标与授权以 rules/rules.md、config 和实时身份为准；读取失败显示“未能读取”，不报零。知识接口的可用状态必须分别实查。

## 运行与发布

电脑须在线且 Windows 用户已登录。watchdog 仅维护监听器，不轮询模型。静态配置变更需安全重启；已新增管理员邀请自动入群的动态准入，依赖后台订阅且不重启。多个业务任务并行尚未实现。人格版本哈希刷新不需要重启监听器。

部署入口见 spec/feishu-codex-personal-assistant-deployment-spec.md；公开仓库发布边界见 spec/repository-publication-spec.md。运行日志、记忆、原始聊天与真实资源配置只在本机保存。
