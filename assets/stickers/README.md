# 机器人表情包

把现成表情包直接放在这个目录，支持 PNG、JPG、JPEG、GIF、WEBP；单文件不超过 10 MB。不要放在子目录里。

文件名用来说明表情的意思和适用语境，例如：

- `笑死了.gif`
- `无语但不生气.png`
- `疑惑你认真的吗.jpg`
- `下班快乐.webp`

每次闲聊都会重新扫描目录，新增、替换和移除素材不需要重启。最多展示前100个合规文件给模型选择；建议只保留少量意思清晰的常用表情包。文件名不要写真实人名、隐私或操作指令。

表情包通过机器人图片消息发送，GIF的实际展示以飞书客户端为准；不是Unicode emoji或消息下方的状态反应。这里不接收飞书原生贴纸的file_key文本文件。

机器人仅在适合的闲聊中选择一个表情包，不每条都发。正式需求、失败说明和需要事实解释的内容用文字回答。目录为空、素材不合规或上传失败时回文字，不把emoji当作替代品，也不声称已发送表情包。

首次选中时按机器人身份上传素材，随后按文件内容缓存图片Key；修改文件会自动使用新缓存。只放允许机器人在现有准入会话中使用的素材，不要放私人照片或其他业务文件。
